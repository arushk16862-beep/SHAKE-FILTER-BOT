# Auto Filter Bot – Customize

This version is based on the supplied sample ZIP.

## Main bot
`/customize` opens two main buttons:

- **Cʟᴏɴᴇ Sᴇᴛᴛɪɴɢs**
- **Mᴏᴠɪᴇ Fɪʟᴛᴇʀ**

Clone Settings lists only the logged-in user's cloned bots.

## Clone bot
Inside a clone, `/customize` provides:

- Start Text
- Start Image
- Buttons
- Force Subscribe
- Auto Delete

The existing movie/auto-filter `/settings` flow is retained.

Bot UI text uses the requested Unicode small-cap style such as `ʜᴇʟᴘ`.
